# 页面映射

采用原生 JavaScript 的 state.page 切换页面，不使用 URL 路由。

- `home`：工作台；入口 `src/app.js`；共享 `index.html` 布局。
- `projects`：项目管理；入口 `src/app.js`；共享 `index.html` 布局。
- `tasks`：任务管理；入口 `src/app.js`；共享 `index.html` 布局。
- `requirements`：需求管理；入口 `src/app.js`；共享 `index.html` 布局。
- `roles`：角色管理；入口 `src/app.js`；共享 `index.html` 布局。
- `teams`：团队管理；入口 `src/app.js`；共享 `index.html` 布局。
- `skills`：技能中心；入口 `src/app.js`；共享 `index.html` 布局。
- `settings`：设置；入口 `src/app.js`；共享 `index.html` 布局。

品牌独立页面：`brand.html`，引用 `assets/brand/`。
