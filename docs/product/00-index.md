## 产品结构

项目 → 需求 → 任务 → 执行记录 Run → 交付版本 → 验收记录。

角色组合职责、CLI、模型配置、Skills 和权限；团队组织角色与负责人；项目选择团队并绑定代码仓库。飞书与桌面端共享同一业务对象，消息渠道不决定任务的身份。

首版以单人所有者、本机执行、单个项目主仓库为范围。多人账号、跨机器执行、多仓库和云同步列入后续版本，不因公开仓库而默认提供这些产品能力。
