# 纬舟 WeftPilot · 品牌说明

## 名称

- 中文：纬舟。
- 英文：WeftPilot，代码与仓库标识为 `weftpilot`。
- 主张：让 AI 团队，有序抵达。
- 产品描述：AI 团队桌面工作台。

“纬”对应把角色、模型、工具和任务编织成协作路径；“舟”对应承载团队共同抵达交付目标。Weft 表示纬线，Pilot 表示领航，英文与中文共享“编织协作、引导交付”的意象。

本轮做了常见重名的初步网络检索。名称为本产品的设计命名，不表示完成商标或域名登记。

## Logo

两个相互交叠的折线路径组成 W：一条深绿代表稳定的项目与执行边界，一条浅绿代表可组合的成员和能力。向下收束再向上展开，表达团队在同一目标下并行推进。

Logo 为本项目原创矢量图形，不依赖位图生成服务。文件可直接编辑、缩放和用于应用图标；小尺寸保留两条路径，避免增加小字与复杂装饰。

| 文件 | 用途 |
| --- | --- |
| `assets/brand/mark.svg` | 透明底双色标志 |
| `assets/brand/mark-mono.svg` | 单色标志 |
| `assets/brand/mark-light.svg` | 深色背景上的浅色标志 |
| `assets/brand/app-icon.svg` | 圆角底应用图标 |
| `assets/brand/wordmark.svg` | 中文 / 英文组合字标 |
| `brand.html` | 品牌展示、缩小尺寸和背景适配预览 |

## 颜色与用法

- 森林绿 `#1A3C2B`：主色、主要操作、深色图标底。
- 纬线绿 `#89A66B`：协作路径和辅助品牌元素。
- 嫩叶绿 `#CFE4AD`：深色背景上的辅助路径。
- 纸白 `#F7F7F5`：工作空间背景。

中文使用系统无衬线字体，英文保持 WeftPilot 的大小写。字标文字保留为可编辑文本；用于发布素材时可在设计工具中转为轮廓。

标志四周至少留一个路径宽度的空白。不拉伸、不旋转、不添加发光或渐变。导航中图标约 28–32px，图标与中文名配合；托盘使用单色图形。
