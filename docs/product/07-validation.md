# 原型验证记录

本轮验证只针对交互原型，不代表真实 CLI、Git、模型、技能市场或飞书服务已经接入。

## 角色流程

- 填写名称、唯一标识和职责后进入六步配置。
- 模拟环境检查通过后可继续选择 Skills 与权限。
- 关闭弹窗并刷新，角色草稿及已选技能可恢复。
- 飞书授权过期后可以重新发起，不丢失角色信息。
- 试运行失败时无法启用；模拟成功后可启用，角色刷新后仍存在。

## 任务流程

- 模拟未提交改动或冲突时，执行前检查阻止启动。
- 角色达到并发上限后任务进入队列，尚未建立新的 Run。
- 释放角色名额后可以调度队列任务，建立独立分支、目录与配置快照。
- 模拟远程操作触发本次 Run 的审批，用户决定后继续原 Run。
- 完成步骤后进入待验收；未逐项检查验收标准时不能通过。
- 退回修改保留修改意见和原 Run；再次执行创建 R2，原 R1 不被覆盖。
- R2 验收通过后，仍能打开 R1 查看原来的分支、配置与退回说明。
- 浏览器控制台未发现以上流程引起的错误。

## 视觉与静态检查

- 检查品牌在浅色、深色和小尺寸下的表现，保留可编辑 SVG。
- 检查角色流程、执行前检查与验收页面的桌面布局。
- `npm run check` 验证 JavaScript 语法、入口资源路径和前端源码中的本机绝对路径。
- Superdesign 五个画面导入成功，回读验证画面版本、关键内容与实际 Logo URL。
