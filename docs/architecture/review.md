## 开发设备需要验证

- 实际 OS/CPU、Electron/Node/SQLite 与原生模块 ABI、签名和系统凭据兼容。
- Agent-Team 无副作用的嵌入式入口、无飞书配置启动、原入口兼容和发布物完整性。
- CLI 的权限、会话、停止与续接能力；不把提示词约束当作系统隔离。
- 飞书应用查询/创建/配置的官方接口与权限；Skill 市场首个来源和版本隔离。
- 内核版本/协议/schema 的锁定与升级恢复；旧数据是否需要显式导入。
- 开源许可证、品牌商标可用性、签名和发行渠道仍待确定。

上述技术验证在开发指令范围内由 M0 完成，无需把每个常规实现点重新提交给用户确认。若发现与已确认目标冲突，说明证据、影响和可选调整。
