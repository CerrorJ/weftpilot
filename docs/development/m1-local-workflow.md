## 实际能力

Agent-Team 统一维护项目、不可变角色版本、Task/Run、幂等命令、SQLite 事务、单执行槽、Git worktree、受控 Codex CLI、交付与验收。桌面通过命名 preload 接口发命令；数据库不暴露给页面，目录由系统选择。

项目展示 Git 地址、默认分支，执行展示实际分支、工作目录及角色配置快照。有未提交改动时拒绝启动，保留用户文件。重试创建新 Run，交付版本随尝试递增；执行成功进入待验收，退回保留原因。日志仅显示持久工具/事件类型，不伪造百分比。

停止请求、停止中、确认结束、状态待确认分开。Windows 直接持有原生 CLI，停止等待进程树；恢复时无结束证据不会自动重放旧执行。排队取消有明确未启动证据。

界面提供中英文、浅色、深色及跟随系统；本机保存偏好，原文任务和交付不改写。系统菜单和原生主题同步，跟随系统用实时媒体查询响应。

## 验证方法

```sh
pnpm kernel:assemble
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
pnpm test:e2e
pnpm package
```

普通 E2E 不调用付费模型，验证真实 Electron/工具进程、锁定版本、项目角色任务、脏保护、偏好及重启。真实模型验收显式启用，在自动创建的隔离测试仓库中执行；仅目录选择替代系统对话框，业务内核和 CLI 不模拟。

```powershell
$env:WEFTPILOT_REAL_CLI = '1'
node --import tsx --test tests/e2e/workflow.test.ts
```

打包后设置 WEFTPILOT_PACKAGED_EXE 为实际应用路径，再运行相同检查；M0 检查另把应用复制到中文/空格/# 安装目录并限制 PATH，不依赖开发 Node。
