## 实际实现

需求详情接回“创建关联任务”，复用普通`TaskCreate`弹窗和内核`task.create`。打开时固定来源需求对象，以标题、内容、验收标准预填任务，允许用户调整任务文本；所属项目固定为此需求的确切项目，需求引用固定为打开时的ID及版本。后台新增需求版本不会改写输入或把任务转绑新版本；关闭后重新打开才能使用当前最新版本。

普通任务创建仍提供原来的项目/需求版本选择；项目详情创建仍走原入口。新增来源固定只作用于明确的需求入口。成功必须收到现有严格命令回执，且原表单仍连接到页面，才关闭弹窗并打开确切任务；拒绝保留输入。Esc只关内层创建，焦点回“创建关联任务”，取消不创建任务。创建后保持待执行，不启动CLI或声称执行成功。
