## 实现边界

命名系统桥接只接收项目UUID、版本和当前显示地址。主进程重新通过同一内核的项目查询核对项目/版本/地址，随后串行写入系统剪贴板，并仅在私有主进程比较刚写入的文本。它不向页面返回其他剪贴板内容，不提供通用文本/HTML/文件读写入口。地址脱敏沿用内核已有实现，桌面不读取.git/config或重写一套Git规则。使用锁定[Electron42原生clipboard API](https://raw.githubusercontent.com/electron/electron/v42.0.0/docs/api/clipboard.md)，保留renderer沙箱与contextBridge来源校验。

新请求的查询结果优先，已经开始的系统写入串行收尾，迟到旧查询不能覆盖新复制。检查后再次核对顶层发送者；失败释放队列供下一次显式操作，不自动重写。UI仅接受与当前项目/版本/地址完全匹配的严格回执；地址或项目更换后旧回执不显示为新成功。没有origin或内核不可用标记时不显示复制操作；地址改变需显式重查，系统写入未能核对时明确提示，不能将收到IPC或点击动作当复制成功。
